# 阶段四执行记录：ResNet-18 同架构 GPU/CPU 对照

## 对照结论

在同一 WSL 主机、同一 PyTorch 2.11.0、同一 ResNet-18 代码、相同 PetImages 划分、随机种子 1、批大小 32、学习率 0.01、无预训练权重和 30 epoch 条件下，GPU 训练总耗时为 CPU 的 **1/8.41**；GPU 最佳验证准确率高 2.02 个百分点。

| 指标 | GPU | CPU | 对比 |
| --- | ---: | ---: | ---: |
| 请求/实际后端 | GPU / `cuda:0` | CPU / `cpu` | 显式指定，无回退 |
| 最佳验证准确率 | 74.24%（第 26 epoch） | 72.22%（第 28 epoch） | GPU 高 2.02 个百分点 |
| 总训练耗时 | 200.0957 s | 1682.4581 s | GPU 快 8.41 倍 |
| 平均每 epoch | 6.67 s | 56.08 s | GPU 快 8.41 倍 |
| 峰值 GPU 显存 | 891,883,008 B（约 850 MiB） | 0 B | CPU 未调用 GPU |
| 指标日志 | 30 条 | 30 条 | 均完成 30/30 epoch |

## 结果解释

本对照可用于说明在相同模型和训练设置下 GPU 的训练耗时优势。GPU 与 CPU 的最优准确率存在 2.02 个百分点差异，可能来自浮点计算、并行数据加载与随机增强实现差异；两者均不应与早期 MobileNetV2 CPU 基线直接计算加速倍数，因为网络结构不同。
