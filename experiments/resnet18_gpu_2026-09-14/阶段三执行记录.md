# 阶段三执行记录

## 当前状态

阶段三已完成。由于 MindSpore GPU 与本机 RTX 5060/CUDA 13.2 不兼容，使用 PyTorch CUDA 12.8 在 WSL 中完成 ResNet-18 的真实 GPU 训练；MindSpore Lite 将在阶段五负责从 ONNX 生成 `.ms`。

## 已完成内容

1. 保留 `train_resnet18.py` 作为 MindSpore 实现和 CPU 代码链路验证。
2. 新建 `train_resnet18_torch.py`，实现显式 GPU/CPU 选择、ResNet-18 训练/验证、最佳 `.pth`、SHA-256、环境记录和逐 epoch 指标日志；请求 GPU 时 CUDA 不可用会直接失败。
3. 使用既有 PetImages 划分（训练集 Cat 895、Dog 894；验证集 Cat 99、Dog 99）完成 PyTorch CUDA 张量运算、单批次训练、检查点写入和 30 epoch 正式训练。
