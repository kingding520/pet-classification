## 可复现命令

在 `artifacts/baseline-2026-09-13/reproduction` 中运行：

```powershell
$env:MPLBACKEND='Agg'
$env:PIP_NO_INDEX='1'
$env:PIP_DISABLE_PIP_VERSION_CHECK='1'
conda run -n mindspore python train.py --platform CPU --dataset_path 'D:\develop\pet-classification\MindSporePetClassification\code\dataset\PetImages' --pretrain_ckpt '.\mobilenetV2.ckpt'
```

模型转换命令：

```powershell
D:\develop\pet-classification\MindSporePetClassification\mindspore-lite-2.9.0-win-x64\tools\converter\converter_lite.exe --fmk=MINDIR --modelFile='.\mobilenetv2.mindir' --outputFile='.\pet_reproduced'
```
