当前本机不具备 MindSpore 2.2.14 GPU 的受支持训练组合。可继续保留 CPU 基线用于开发和端到端验证；若要完成报告中的 GPU 训练目标，应改用具备兼容 NVIDIA GPU 的 Linux 主机，或先建立独立的旧版 Linux/CUDA 测试环境并接受其对 RTX 5060 的兼容性风险。

## 与项目目标的差异

中期报告拟采用 Ubuntu 18、Python 3.9、CUDA 11 和 MindSpore 2.2.14。MindSpore 官方 2.2.14 发布清单提供的 Linux GPU 构建对应 CUDA 10.1、11.1 或 11.6；GPU 安装说明列出的验证系统为 Ubuntu 18.04、Python 3.9 至 3.11、CUDA 11.1 或 11.6。

当前环境存在三项差异：

1. WSL 为 Ubuntu 24.04，不是目标 Ubuntu 18.04。
2. 已安装 CUDA 13.2 运行时，不是 MindSpore 2.2.14 GPU 构建所要求的 CUDA 11.x。
3. RTX 5060 的计算能力为 12.0，晚于 CUDA 11.x 和 MindSpore 2.2.14 的发布时期；即使强行安装旧版 CUDA 环境，也不属于受支持组合，可能出现设备架构不识别或内核无法执行的问题。

## 已完成检查

- Windows 与 WSL 均已通过 `nvidia-smi` 确认 GPU 可见。
- WSL 可以访问 Windows NVIDIA 驱动，不需要在 WSL 中另行安装显卡驱动。
- 当前 WSL 未安装 Conda，系统 Python 为 3.12.3，不符合 MindSpore 2.2.14 的 Python 3.9 目标。
- 当前 Windows CPU 基线环境、已复现模型和 Android 端模型均保持可用。

## 2026-09-13 本机 GPU 冒烟实测

已在 WSL Ubuntu 的独立 Python 3.12 虚拟环境中安装 MindSpore 2.10.0，并显式执行 `ms.set_device("GPU")` 与张量乘法冒烟测试。测试未进入训练：MindSpore 报告 `libcuda.so`、`libcudnn.so` 缺失，随后以“仅支持 CPU”拒绝设置 GPU 后端。

进一步核对发现，该 wheel 内置的 GPU 插件为 `libmindspore_gpu.so.11.1` 与 `libmindspore_gpu.so.11.6`；11.6 插件还需要 `libcublas.so.11`、`libcudnn.so.8`、`libcudart.so.11.0`、`libcusolver.so.11`、`libcufft.so.10`、`libcusparse.so.11` 和 `libnvrtc.so.11.2`。本机 WSL 仅有 CUDA 13.2，且没有 cuDNN，故无法加载插件。RTX 5060 也不应通过强行补装 CUDA 11.x 作为结题 GPU 训练依据。

## 推荐执行分支

### 分支 A 兼容 GPU 主机

使用带 NVIDIA GPU 的 Linux 主机，并按 MindSpore 2.2.14 官方 GPU 组合建立隔离环境：Python 3.9、CUDA 11.1 或 11.6、对应 cuDNN 和 MindSpore 2.2.14。先完成 GPU 张量计算和 ShuffleNetV2 单步训练，再开始正式训练。

### 分支 B 本机 CPU 继续验证

继续使用已验证的 MindSpore 2.9.0 CPU 环境完成 ShuffleNetV2 数据、代码和小规模训练验证，同时保留本记录作为 GPU 环境无法按原方案完成的工程证据。

### 分支 C 本机旧版隔离环境试验

在独立 Ubuntu 18.04 WSL 或容器中安装 Python 3.9、CUDA 11.6 和 MindSpore 2.2.14，不改动现有 Ubuntu 24.04、CPU Conda 环境或项目代码。该分支需要下载多个大型系统/深度学习依赖，且对 RTX 5060 不提供成功保证；仅适合作为兼容性试验，不宜作为结题的唯一 GPU 路径。

## 下一步验证标准

无论选择哪一分支，必须依次通过：

1. `nvidia-smi` 与 MindSpore GPU 上下文均可识别目标 GPU。
2. 简单张量计算实际在 GPU 上执行。
3. ShuffleNetV2 单批次前向与反向传播完成。
4. 训练日志、环境版本与错误信息存档。

## 分支 B 执行结果

已于 2026-09-13 在独立实验副本 `experiments/shufflenetv2_cpu_2026-09-13` 中完成 ShuffleNetV2 0.5x 的 CPU 训练。训练使用 PetImages 猫狗二分类数据、批大小 32、30 个 epoch，最终在 198 张验证图像上得到 74.24% Top-1 准确率。完整训练记录和最终检查点信息见该实验目录下的 `训练记录.md`。
